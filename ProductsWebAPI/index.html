Products API Documentation

GET All Products

GET /api/products Returns the full products catalog

GET Product by ID

GET /api/products/{id:int} Returns the particular product for the input id

POST Endpoint

POST /api/products Creates a new product object

PUT Endpoint

PUT /api/products/{id:int} Updates an existing product object by Id

DELETE Endpoint

DELETE /api/products/{id:int} Deletes an existing product with the input id
